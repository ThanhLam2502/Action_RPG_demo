# Design Pattern sẽ học

Trong project nhỏ này bạn sẽ chạm tới gần như toàn bộ những pattern quan trọng của Unity:

- Singleton
- State Machine
- ScriptableObject
- Observer/Event
- Object Pool
- Factory
- Interface
- Strategy
- Command (cho Skill)
- Dependency Injection (nếu muốn)
